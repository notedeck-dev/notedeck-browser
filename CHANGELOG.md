# Changelog

## 0.1.0 (unreleased)

- Context menus: post this page / selection / link / image URL via NoteDeck's post form (`notedeck://compose`, no token)
- Context menus on Misskey note and user URLs: open in NoteDeck (users are resolved through the API, token needed)
- Toolbar popup: edit the text, open NoteDeck's post form, or post directly through the API (confirmed in NoteDeck)
- Omnibox keyword `nd <text>` and keyboard shortcut (default Alt+Shift+N) to open the post form
- Options: API URL, token, connection check. English and Japanese UI
